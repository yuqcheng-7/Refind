# 拾藏连接（Chrome 扩展 · v0.2.2）

在你**自己的浏览器**里打开链接再抽正文（后台标签页，带登录态与完整渲染），避开机房 IP 风控。

## 安装 / 更新（重要）

1. Chrome / Edge 打开 `chrome://extensions`
2. 打开 **开发者模式**
3. 若已加载：点 **重新加载**；若提示新权限，请允许（需 `tabs` + `scripting`）
4. 确认版本为 **0.2.2**
5. 硬刷新 https://www.refind.cloud（Cmd+Shift+R）

首次或权限变更后，扩展会短暂打开后台标签页抓取你粘贴的链接——这是预期行为。

## 怎么用

1. 同一 Chrome **先打开并登录**抖音 / 知乎等（微信公众号一般不用登录）
2. 设置 → 连接内容平台 → 连接
3. 知识库粘贴链接 → 添加资料

若仍失败：点开资料看错误详情，或确认扩展图标在拾藏站点上显示为已启用。
