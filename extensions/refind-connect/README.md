# 拾藏连接（Chrome 扩展 · 今日可用版）

在你**自己的浏览器**里登录平台，扩展把 Cookie 交给拾藏网站。  
不走云服务器扫码，因此不会触发机房 IP 风控。

## 今天怎么装（开发者模式，无需上架）

1. Chrome / Edge 打开 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. **加载已解压的扩展程序** → 选本目录  
   `extensions/refind-connect`
4. 确认扩展已启用

## 怎么用

1. 用同一个 Chrome **先打开并登录**小红书（或抖音 / 知乎 / B 站）
2. 打开 https://www.refind.cloud → 设置 → 连接内容平台
3. 点「连接」→ 扩展自动读取登录态并完成连接

若提示未检测到扩展：确认扩展已启用，并硬刷新拾藏页面（Cmd+Shift+R）。
