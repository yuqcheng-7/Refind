# 拾藏连接（Chrome 扩展 · v0.2）

在你**自己的浏览器**里：

1. 登录小红书 / 抖音 / 知乎 / B 站，把登录态交给拾藏（避开机房扫码风控）
2. **抓取普通网页 / 微信公众号正文**（用你本机网络，比云服务器更容易打开国内站点）

## 安装 / 更新

1. Chrome / Edge 打开 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. **加载已解压的扩展程序** → 选本目录 `extensions/refind-connect`  
   （若已加载过：点扩展卡片上的 **重新加载**，然后硬刷新拾藏页面）
4. 首次加载会申请访问所有网站的权限，用于抓取你粘贴的链接正文——这是预期行为

## 怎么用

### 连接平台（小红书等）

1. 同一 Chrome **先打开并登录**对应平台
2. 打开 https://www.refind.cloud → 设置 → 连接内容平台
3. 点「连接」

### 导入链接（公众号 / 人人都是产品经理等）

1. 确保扩展已启用，并硬刷新拾藏（Cmd+Shift+R）
2. 在知识库粘贴链接 → 添加资料  
   扩展会在你浏览器里打开页面并抽取正文

若提示未检测到扩展：确认扩展已启用，并硬刷新拾藏页面。
