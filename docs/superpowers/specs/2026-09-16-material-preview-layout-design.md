# 知识库资料预览页排版规范

**日期：** 2026-09-16  
**状态：** 已确认  
**范围：** 预览页共享骨架 + 链接 / 本地文件 / 视频三类正文阅读规范  
**非目标（后续专项）：** 视频 ASR、视频帧理解、MediaCrawler「听懂/看懂」视频

---

## 1. 问题

当前预览页「乱」主要来自：

- 同一页头下，链接 / PDF / Word / Markdown / 视频各长一个样（宽度、字号、分区不一致）
- 链接正文被短句硬切，可读性差；标题启发式过激
- Word 插图可横向溢出正文栏
- 操作按钮位置突兀或信息层过密

## 2. 实现路径（已选）

| 方案 | 说明 | 取舍 |
|------|------|------|
| A. 仅改 CSS | 快速统一观感 | 解决不了分段/标题逻辑 |
| **B. 共享骨架 + 分类型阅读器（推荐）** | 页头/摘要/分区统一；正文按类型套阅读规范 | 改动集中在预览组件与 `materialPreview` 分段逻辑 |
| C. 全部打成纯文本 | 最整齐 | 丢掉 PDF/Word/MD 格式预览价值 |

**选定 B。**

---

## 3. 共享骨架（全类型）

顺序固定：

1. **Kicker**（网页资料 / 本地文件 / 视频资料）
2. **标题**（独占一行）
3. **操作按钮**（标题正下方，始终可见，带 icon）
   - 重新解析：`RefreshCw`
   - 回到原文（链接）/ 打开原文件（本地）：`ExternalLink`
   - 浅描边按钮，非顶栏右上角悬浮
4. **事实栏**（单行横排，略紧凑）
   - 保留「小标签 + 值」：`来源` · `类型` · `时间` · `标签`
   - 四项同一行；窄屏标签过长省略，不折成第二层
5. **摘要**（分区标题「摘要」+ 左侧引述条样式，沿用现有引用块视觉）
6. **正文区**（分区标题随类型：`原文` / 视频则为播放器区标题策略见 §6）

视觉原则：少卡片、少色条堆叠；摘要保留引述是唯一强调块。

---

## 4. 链接文章阅读规范

适用于微信 / 知乎 / 小红书等非视频链接。

| 项 | 决策 |
|----|------|
| 节奏 | **L1 杂志长文**：舒适行距、图文穿插 |
| 标题 | **H1**：仅「一、」「1.」「1、」等编号大纲行升为标题样式；短句不升格 |
| 分段 | **P1**：只按原文空行/自然段分段；**禁止**按短句或 ~120 字硬切 |
| 文内图 | 按 `![](storage:…)` 顺序插在段落间；`max-width: 100%`，圆角 |
| OCR / 画面描述附录 | 预览**默认折叠**（可展开）；内容仍写入 `content_text` 供 RAG |
| 说明 | 无字图片仍可有「画面描述」；折叠块标题可用「图片识别」 |

## 5. 本地文件阅读规范

| 项 | 决策 |
|----|------|
| 策略 | **分类型预览 + 统一页头**（PDF 内嵌、DOCX HTML、MD 渲染、图片、Office→PDF 等保持） |
| 栏宽 | 与链接正文同一阅读栏（约 740px 内容宽）；PDF/图片预览不得无故撑到另一套宽度体系 |
| Word 插图 | **宽高都限**：`max-width: 100%`；过高则等比缩小，约不超过一屏（如 `max-height: min(70vh, 720px)` + `object-fit: contain`） |
| Markdown / 纯文本 / 结构化 | 套同一正文字号与间距 token，避免「另一种产品」感 |
| 打开原文件 | 与链接「回到原文」同位置、同按钮样式 |

---

## 6. 视频阅读规范

| 项 | 决策 |
|----|------|
| 顺序 | **播放器 → 文案/简介**；**字幕默认折叠** |
| 无文案 | 预览仍可播；检索能力有限（标题/薄元数据）——产品如实接受 |
| MediaCrawler | 仅标题/简介/评论/媒体 URL；**不做**听懂/看懂；ASR 与帧理解列为后续专项 |

---

## 7. 设计 token（预览页）

实现时收敛到一套变量（数值可微调，原则固定）：

- 正文：约 15.5–16px，行高约 1.85–1.9
- 分区标题「摘要 / 原文」：约 15px 字重 700
- 事实栏标签：约 11px 次要色；值约 13.5px
- 操作按钮：高约 32–34px，icon 12–14px + 文案
- 摘要引述：左 3px 深色条 + 浅底

---

## 8. 主要改动面

- `MaterialPreviewPage.jsx`：骨架重排；按钮下移并加 icon；事实栏单行
- `materialPreview.js`：分段改为 P1；标题检测收紧为 H1；OCR 附录拆出供折叠
- `MaterialFilePreview.jsx` + `styles.css`：docx/md/等宽度与 Word `img` 约束；预览 token 统一
- 测试：`materialPreview.test.js`、预览页相关组件测

---

## 9. 验收

1. 任意类型预览：标题下可见带 icon 的重新解析 + 原文/原文件；事实栏四项单行  
2. 摘要为引述块且有「摘要」标题；正文有对应分区标题  
3. 微信长文：段落不碎切；仅编号大纲像标题；文内图不撑破；图片识别默认折叠  
4. 含图 Word：插图不横向溢出，过高被限制在约一屏内  
5. 视频：播放器后接文案；字幕默认折叠  
6. 不做视频 ASR（本切片）
