# 会话历史分面与持久化（首页 / 知识库）

> 日期：2026-09-15  
> 状态：**已落地**（`refind-demo` + Tokyo Supabase）  
> 关联：`2026-09-15-rag-chat-foundation-design.md`、迁移 `202609150004` / `202609150005`

## 1. 目标

把首页与知识库的「历史会话」从演示列表升级为真实持久化，并保证：

1. **首页历史**与**知识库历史**互不混入。
2. **不同知识库**的会话列表彼此独立。
3. 「新增会话」立刻在列表中出现草稿，而不是等到首条消息才建行。

## 2. 数据模型

`chat_conversations` 增加：

| 字段 | 含义 |
| --- | --- |
| `surface` | `home` \| `knowledge` |
| `knowledge_base_id` | 知识库会话必填；首页通用会话为 `null` |

列表规则：

- 首页历史：`surface = home`
- 知识库历史：`surface = knowledge` **且** `knowledge_base_id = 当前库`

## 3. 写入规则

| 入口 | 落库 |
| --- | --- |
| 首页「新增会话」 | 立刻插入 `surface=home`、标题「新会话」 |
| 知识库「新建会话」 | 立刻插入 `surface=knowledge` + 当前 `knowledge_base_id`、标题「新会话」 |
| 首页未选知识库提问 | `surface=home`（可续写空草稿） |
| 首页只选 **1** 个知识库提问 | 记入该库的 `knowledge` 历史（空首页草稿可在首条消息前改绑） |
| 首页多选知识库 / 仅标签 | 仍记 `home`（无法唯一归属单库） |
| 知识库 AI 面板提问 | 始终 `knowledge` + 当前库 |

首条有效用户消息后：若标题仍是「新会话 / 未命名会话」，用问题原文截断更新标题。

续写时：服务端校验会话的 `surface` / `knowledge_base_id`；不匹配则新开会话，避免串库。空草稿允许在首条消息前改绑到正确分面。

## 4. 交互

- **重命名：** 右键菜单 → 列表内联编辑；回车 / 失焦保存，Esc 取消；**无弹窗**。
- **删除：** 二次确认后硬删会话及其消息与引用。
- **切换知识库：** 清空当前库对话态与历史菜单，重新加载该库会话列表，并**默认选中该库最新一条历史会话**展示（无历史则空状态）。
- **进入知识库页：** 与切换知识库相同——加载完成后默认打开最新会话（按 `updated_at` 倒序第一条）；再次点同一库导航也会回到最新会话。
- **首页进入对话：** 「首页」导航在已有历史时打开最新首页会话（既有行为，保持）。
- **首页空对话文案：**「有什么想聊的？直接提问，或在输入框里选择知识库。」（单行展示）
- **历史列表图标：** 圆形会话气泡（`MessageCircle`）。
