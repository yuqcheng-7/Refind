# Refind 原型交互修正设计（2026-09-13）

> 状态：Task 1–4（浮层 / 首页会话分离 / 资料预览）与 Task 5（首页对话壳 + 回答分享选气泡）均已在原型落地  
> 适用范围：`refind-demo` 高保真原型 + 同步回写 PRD / Spec / `design.md`  
> 关联计划：`docs/superpowers/plans/2026-09-13-menus-home-ai-material-preview.md`

## 1. 背景

在笔记/灵感原型与导航响应式修复之后，产品确认了三类交互修正，以及随后在首页对话壳、回答操作与分享链路上的细化决策。本文档为当前已确认行为的单一设计真源摘要。

## 2. 已确认决策

### 2.1 全局浮层关闭

- 所有按钮弹出的 menu / popover / dialog（账号、筛选、添加资料、首页知识库/标签、模型、会话历史、rail 切换、回答收藏/更多等）必须支持：
  - 点击浮层外任意区域关闭；
  - `Esc` 关闭。
- 打开新浮层时应关闭其他互斥浮层。
- **回答操作菜单**（收藏、更多）使用页面级浮层（`position: fixed` + 高 `z-index` / portal），必须压过输入框、分享栏、历史卡片与滚动容器，不得被裁切或盖住。

### 2.2 添加资料队列恢复

- 解析成功后，该队列卡片自动消失，并将工具行恢复为「搜索 / 筛选 / 添加资料」同行布局。
- 失败卡保留重试/删除；连续三次失败仍降级为仅链接/仅附件。
- 原型不接真实上传/解析网络。

### 2.3 首页 AI 与知识库 AI 分离

- `homeMessages` 与 `kbMessages` 两套会话，互不跳转、互不共用。
- 首页发送后：**留在首页**。欢迎区（机器人 + Welcome 文案）收起，对话流在输入区域上方展开；底部 composer 可继续追问。
- 首页仍支持：无范围 = 通用任务（默认可不联网）；有知识库或 `#` / `@标签` = 严格 RAG / 不联网。
- 知识库 AI 仅服务当前知识库追问；新建会话只清知识库会话。
- 用户气泡 / 回答样式按首页对话流单独校正。

### 2.4 首页对话壳与历史（已落地）

- 表面状态：`hero` | `chat`。
- 品牌「拾藏」→ 回到 hero，**保留**最近一次会话内容；「首页」导航 → 若已有会话则恢复 chat（默认打开最新历史会话）。
- 「+ 新增会话」清空气泡，但仍留在 chat 表面（不回到 hero）。
- 进入 chat 后出现左侧 **历史会话浮动卡片**（背景 `#FCFCFB`）：展开含「+ 新增会话」、搜索、按时间分组列表；可折叠为 FAB。
- **左右留白：** 无论历史卡展开或折叠，对话列（含输入框）在可用区域内水平居中，左右外边距一致。历史展开时内容区左侧留白 = 历史卡右缘到对话列的间距 = 右侧画布边距（各 32px）；折叠时画布左右 padding 均为 32px。对话列 `max-width: 880px`。
- 对话区独立滚动、滚动条隐藏；composer / 分享栏固定在对话区底部。

### 2.5 首页 composer（已落地）

- 占位：`请输入内容进行提问，输入 # 可选择标签`；字号约 14px。
- Enter 发送，Shift+Enter 换行。
- DeepSeek 模型菜单：快速 / 深度 → 芯片文案 `DS快速` / `DS深度`。
- 默认不联网；选知识库或标签后强制不联网。
- 发送钮：黑色圆形 `#111`，视觉上始终可点（空内容不提交）。
- 范围芯片为 pill；去掉多余「通用任务 / 严格 RAG」说明性大字 chrome。

### 2.5.1 知识库页默认会话（2026-09-17）

- 进入知识库页或切换知识库后，默认选中并展示该库**最新一条**历史会话（有消息则渲染对话；无历史则空态「从你的知识库中寻找答案」）。
- 「新建会话」仍清空当前气泡并插入新草稿。

### 2.6 回答操作与分享选气泡（已落地）

图标顺序（左→右）：**复制 → 收藏 → 分享 → 更多**。

| 操作 | 行为 |
| --- | --- |
| 复制 | 复制整答；按钮旁短暂提示「已复制」 |
| 收藏 | 在触发器旁弹出「保存为灵感卡片 / 加入笔记」；划选文字同样走该菜单 |
| 分享 | 进入选气泡模式（见下） |
| 更多 | 「删除回答」「反馈」 |

**分享模式：**

1. 点击分享后进入选气泡；默认勾选当前回答气泡。
2. 用户气泡与回答气泡均可点选；左侧平面勾选圈（未选描边、选中实心黑 `#111`），未选气泡略淡，不使用亮蓝描边铺底。
3. **整块替换**底部输入框为分享栏：左侧「已选择 N 条气泡」，右侧「复制对话链接」主按钮 +「取消」次按钮；按钮字号/圆角/色值与主题主次按钮统一（主：`#111` + 10px 圆角；次：`#FDFDFD` + `#E2E4E7` 边框）。
4. 「复制对话链接」成功后 Toast「对话链接已复制。」并 **自动退出**分享模式，恢复 composer。
5. 「取消」、新增会话、切换历史、离开首页均退出分享模式。

### 2.7 资料 hover 与打开

- Hover 资料行：展示完整文件名/标题 + AI 解析摘要。
- **点击任意资料**（链接或文件）：新窗口打开应用内资料预览页，展示标题、来源、摘要与**已解析正文**。
- 链接类额外提供「在原站打开」。

### 2.8 已落地 UI 基线（回写）

- 应用壳 **全宽**；拾藏强调色以 **黑色** 为主。
- 侧栏品牌：英文 `Refind` + 中文「· 拾藏」均为**纯黑**实色（`#111`），不使用渐变字色。
- 侧栏：边缘半出圆形折叠钮；知识库导航为文件夹图标；桌面可折叠、平板图标轨、手机抽屉。
- 知识库页：资料列与 AI 列竖分割线通高；工具行搜索/筛选/添加资料；AI 输入区 DeepSeek + `#` 标签上弹出。

## 3. 原型数据约定

资料至少包含：

| 字段 | 说明 |
| --- | --- |
| `kind` | `link` \| `file` |
| `url` | 链接类原 URL；文件可空 |
| `fileName` | 展示用文件名/标题 |
| `summary` | AI 摘要 |
| `body` | 预览窗正文（已解析内容） |
| `source` / `tag` / `time` / `base` | 现有列表字段 |

首页分享原型链接形态：`https://refind.app/share/home?bubbles=<id,...>`（演示用，不要求真实后端）。

## 4. 验收要点

1. 任一打开的菜单，点击空白处或 Esc 可关闭；回答菜单不被底栏/历史卡遮挡。
2. 解析成功后工具行恢复，成功队列卡消失。
3. 首页提问不跳转知识库；欢迎区让位给对话流；品牌/首页/新增会话表面切换正确。
4. 知识库提问仍只在知识库 AI 面板。
5. Hover 见摘要；点击开预览窗；链接可再开原站。
6. 分享：可选气泡 → 底栏替换 → 复制链接后自动退回对话；取消可退出。
7. 既有 notes / nav / home / knowledge 测试不回归。
