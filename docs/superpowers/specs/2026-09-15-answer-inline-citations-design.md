# AI 回答可读性与行内引用浮卡设计

> 日期：2026-09-15  
> 状态：已确认（用户选 A：浮卡）  
> 范围：首页 + 知识库 AI 回答渲染

## 目标

1. 回答按分段/列表/加粗可读展示，避免「一整坨」。
2. `[n]` 作为行内可点角标，跟在对应句/段后。
3. 点击弹出浮卡：资料标题、摘录、「查看资料」。
4. 去掉回答底部引用芯片堆。

## 非目标

- 完整 Markdown 引擎 / 数学公式
- 历史会话持久化列表
- 改动笔记编辑器引用

## 实现要点

- 共享 `AnswerContent`：规范化换行 + 轻量 inline（`**bold**`、`[n]`）
- 浮卡 dismissable；「查看资料」走已有预览 URL
- RAG system prompt 要求：中文分段、列表换行、句末 `[n]`
