# 笔记工作台收紧与全屏入口设计（2026-09-13）

> 状态：已与产品确认（含选择条弱渐变圆角、笔记引用 hover 预览）  
> 适用范围：`refind-demo` 笔记 / 灵感卡片模块；同步回写 PRD / Spec / `design.md`  
> 开发计划：`docs/superpowers/plans/2026-09-13-notes-workspace-remediation.md`

## 1. 背景

笔记模块当前页头冗余（「个人记录」）、密度偏松且视觉偏右下；列表工具为上下两行；灵感页筛选占位；「新建笔记」与「整理为笔记」进入编辑的路径未完全区分素材面板。本修订统一布局与两种创作入口。

## 2. 信息架构（已确认）

- **「我的笔记」** 与 **「灵感卡片」** 是两个独立入口。
- 灵感卡片 **只用于创作笔记**（素材库），不是第二套笔记列表。
- 页头只显示标题「笔记」，**去掉**「个人记录」eyebrow。

## 3. 布局与控件

### 3.1 页头（T1）

- 左侧仅 `h1`「笔记」；右侧「新建笔记」为 **黑色主按钮**（`#111`），与标题文字底边 **水平对齐**。
- 整体收紧：减小 header / tabs / 列表 / 编辑区 padding，纠正内容区偏右、偏下的留白。

### 3.2 我的笔记列表工具行（T2）

- **笔记本选择器缩小**，与 **搜索笔记** 同一行（不再上下堆叠）。
- 默认文案「全部笔记」；下拉仍含各笔记本与「管理笔记本」。

### 3.3 灵感卡片工具栏（T4）

- **去掉筛选**（来源/时间筛选入口移除）。
- 搜索栏水平延伸至「整理为笔记」按钮之前。
- 「整理为笔记」选择态逻辑不变。

### 3.4 选择条视觉（已确认 · 后续打磨）

进入「整理为笔记」选择态后的已选条（`.cards-selection-bar`）：

- **形状**：内嵌圆角长条（约 `12px` 圆角），**不是**左右通栏贴边条。
- **底色**：左浅右深的克制横向渐变，最终定为  
  `#EEEEED → #E9E9E8 → #E8E8E7`  
  （相对纯色 `#E9E9E8` 只保留极弱对比；避免左边过亮、右边过深）。

## 4. 编辑入口与素材面板（已确认）

| 入口 | 界面 | 底部素材面板 | 「生成笔记」 |
| --- | --- | --- | --- |
| 「新建笔记」（我的笔记或灵感卡片 Tab） | 全屏编辑 | **不显示** | 不显示 |
| 「整理为笔记」勾选卡片后开始整理 | 全屏编辑 | **显示**（带入所选卡片） | 显示（素材非空时可点） |
| 「我的笔记」双栏中，「已保存」左侧全屏 icon | 全屏编辑 | 若该笔记 **已有** `inspirationCardIds` 则 **显示**；否则不显示 | 有素材时显示 |

### 4.1 全屏返回

- 全屏提供返回；退出后回到 **「我的笔记」** Tab。
- 列表中出现/保持该笔记，并 **选中** 该笔记（双栏可继续编辑）。

### 4.2 灵感页点「新建笔记」（T5）

- 立即创建「未命名笔记」并进入 **无素材** 全屏编辑。
- 返回后：切到「我的笔记」、列表可见新笔记并选中。

### 4.3 双栏内全屏 icon（T3）

- 位置：右侧编辑区顶部工具栏，「已保存 / 正在保存」文案 **左侧**。
- 行为见上表第三行。

### 4.4 生成正文中的笔记引用（已确认 · 后续打磨）

- 由灵感卡片生成的正文，关键要点句末以内联 `[n]` 标记呈现；**不**再附加「（来源：…）」纯文本。
- 每个引用节点绑定对应灵感卡片 `cardId`（及引用标签快照）。
- **Hover** `[n]`：在角标旁展开可点击预览菜单，展示来源标签、卡片摘录、原问题与「点击查看灵感卡片」提示。
- **点击**角标或预览菜单：打开既有灵感卡片详情弹窗（可加入笔记 / 删除）。
- 预览菜单须做视口边界夹取：默认优先右对齐角标；贴右缘时向左展开，避免超出屏幕。

## 5. 验收要点

1. 笔记导航进入后无「个人记录」；新建按钮黑、与标题底对齐；页面更紧凑、不偏右下。  
2. 笔记本筛选与搜索同一行。  
3. 已保存旁有全屏 icon；有素材笔记全屏可见素材面板。  
4. 灵感页无筛选；搜索贴到整理按钮前；选择条为内嵌圆角长条 + 左浅右深弱渐变。  
5. 灵感页新建 → 无素材全屏；整理 → 有素材全屏；返回均到我的笔记并选中对应笔记。  
6. 生成正文 `[n]` hover 出预览且不越界；点击可打开对应灵感卡片详情。  

## 6. 非目标

- 不改笔记同步知识库、删除笔记本策略、灵感卡片详情弹窗主流程。  
- 本迭代不恢复灵感页来源/时间筛选（若以后需要另开需求）。
