# Refind 拾藏设计规范（当前定稿版）

> 本文档记录当前前端 Demo 的已落地视觉与交互状态，作为后续迭代基线。除非明确提出变更，页面应保持本文定义的结构与风格。
>
> 最近修订：2026-09-13（§6/§8/§10.4：选择条弱渐变圆角长条；笔记生成引用 hover 预览与回卡片）

## 1. 设计定位

Refind 拾藏是个人资料收藏、归集与知识库提问工具。整体采用克制、轻盈、偏产品化的桌面端界面：大面积乳白底色、细灰蓝分割线、轻微粉色环境光，以及深色操作按钮形成清晰的功能层级。

核心原则：

- 内容优先，避免卡片堆叠与过度装饰。
- 通过留白、细分割线和少量深色操作点建立层级。
- 动效只用于低对比的微交互；当前知识库 AI 输入区不使用流动边框。
- 中文文案使用常规字重为主，避免过强的“AI 感”。

## 2. 全局基础

| 项目 | 当前规范 |
| --- | --- |
| 页面底色 | `#FCFBF9`，右下保留柔和蜜桃粉环境渐变 |
| 主文字 | `#111923` / `#17202C` |
| 次级文字 | 灰蓝系，如 `#78889E`、`#8B9AB0` |
| 分割线 | 半透明灰蓝，如 `rgba(151,164,181,.30)` |
| 主要深色按钮 | `#0F1D2B` 或 `#101923` |
| 圆角 | 操作按钮 8–12px；首页输入框 22px；不要过度使用大圆角卡片 |
| 字体 | `DM Sans`（拉丁）+ `Refind Source Han SC`（中文），回退为 PingFang SC / Microsoft YaHei |

## 3. 应用框架

### 3.1 左侧导航栏

- 桌面展开态宽度约 220px，白色半透明底，右侧使用极细分割线。
- 侧栏顶部或底部提供明确的折叠按钮：展开态显示图标与文字、知识库列表和账号信息；收起态仅保留导航图标，文字与知识库列表隐藏。收起态图标须保留 tooltip 或等价名称。
- 顶部使用深蓝 Refind Logo 图片，尺寸 28px。
- Logo 底边与 “Refind · 拾藏” 文案底边对齐。
- 导航包含：首页、笔记、知识库。
- 当前页采用白色轻玻璃高亮：细边框、极弱外阴影、克制内高光。
- “新建知识库”加号 hover 时保留旋转微动效。
- 知识库搜索框仅保留底部细线；知识库列表处于知识库页时展示。
- 账号区域点击后显示设置与退出登录。

### 3.2 页面背景

- 首页、笔记与知识库页共用乳白底色。
- 右下角使用柔和蜜桃粉渐变，向中心消散；不可替换为高饱和色块或明显光圈。
- 左上区域可保留很轻的淡紫灰提亮。

### 3.3 尺寸与响应式

- 桌面设计基准为 1920px 宽。**2026-09-13 起原型采用全宽工作台**（不再强制 1200px 左对齐安全区）；宽屏下栏位随视口分配，背景仍可保留弱渐变。
- `≥1200px` 为桌面工作台：保留多栏信息结构；全局导航可在展开态与图标态切换。
- `768–1199px` 为平板紧凑布局：全局导航默认图标态；笔记保留列表与编辑区两栏，知识库保留资料列表；AI 对话、筛选和素材面板均改为覆盖式面板。
- `<768px` 为移动单栏：全局导航移入左侧抽屉；笔记仅展示列表或编辑器之一；知识库默认展示资料列表，AI 对话、筛选与素材面板均以覆盖式面板打开。
- 移动端不缩放桌面多栏来适配；触控目标不得小于 44px，文本、标题与编辑工具必须可读可点。

## 4. 首页

- 顶部主视觉使用提供的机器人资产；不再使用八角芒星作为主视觉。
- 标题：`Welcome, Refind!`。
- 副标题：`把散落的收藏，重新捡回来。`。
- 首页不显示三张快捷入口卡片。
- 首页 AI 输入框居中偏下，保持较宽的圆角乳白玻璃容器；提示语为“请输入内容进行提问，输入 # 可选择标签”（约 14px）。
- 首页输入框包含：模型芯片（`DS快速` / `DS深度`）、联网/不联网开关、多选知识库选择器、圆形黑色发送按钮；标签通过输入 `#` 上拉；不提供资料上传加号。
- Enter 发送，Shift+Enter 换行；默认不联网；选中知识库或标签后强制不联网并进入严格 RAG。
- 多选知识库时，在输入框内紧凑显示已选数量/名称，检索语义为知识库并集；多选标签使用 AND 关系。只选标签时，范围为全部知识库内的对应标签。
- 通用 AI 回答不展示“参考资料”或引用标识；严格 RAG 回答显示范围与资料引用。模型、联网和范围选择在当前会话持续保留，直至用户修改或新建会话。
- **对话壳：** 发送后欢迎区收起，进入 `chat` 表面；品牌「拾藏」回 hero 并保留会话；导航「首页」可恢复 chat；「新增会话」清气泡仍留在 chat。
- **历史卡：** chat 后出现左侧浮动历史会话卡（`#FCFCFB`），可折叠为 FAB；展开时对话与输入共宽左对齐，折叠时对话居中。
- **回答操作：** 复制 → 收藏 → 分享 → 更多；菜单为页面顶层浮层。
- **分享：** 选气泡（左侧平面黑勾选圈）→ 底栏替换为「复制对话链接 / 取消」（主题主次按钮）→ 复制成功自动退回 composer。
- **2026-09-13：** 首页发送后对话留在首页，**不跳转**知识库 AI；与知识库会话状态分离。

## 5. 知识库页：三栏结构

### 5.1 布局

页面由左侧全局导航、中部资料列表、右侧 AI 对话组成。

- 中部资料区与右侧 AI 区之间使用一条从页面顶部贯通至底部的直线分割。
- 右侧 AI 区顶部与中部知识库名称水平对齐。
- 中部资料区取消白色卡片外框，直接置于页面底色上。
- 右侧 AI 区同样不使用包裹式白色卡片或圆角外框。

### 5.2 中部资料列表

- 标题只显示当前知识库名称，例如“默认知识库”。
- 工具栏顺序：搜索资料、筛选、添加资料。
- “添加资料”为深色主按钮；点击打开菜单，提供“粘贴链接”和“上传文件”。上传支持链接、图片、PDF、DOC/DOCX、Markdown、TXT、PPTX、XLSX、CSV。
- 搜索聚焦后占满工具栏，显示清除按钮，并暂时隐藏筛选与添加资料。
- 筛选菜单包含来源（小红书、抖音、微信、知乎、B 站、其他）与排序（从新到旧、从旧到新、A–Z、Z–A）。
- 添加链接按钮为深色按钮，圆角约 12px，保持左右对称。
- 资料行使用书本图标、标题、来源/标签与日期；标题为 13px，正文/元信息更淡。
- Hover 资料行显示完整文件名/标题与 AI 解析摘要；点击打开应用内资料预览新窗口（链接与文件均如此）；链接预览提供「在原站打开」。
- 多文件上传时，“添加资料”位于工具行；队列卡片展示解析进度；**解析成功后卡片消失并恢复工具行**。列表内资料成功入库后显示来源与标签。
- 失败资料行保留失败原因与重试/删除操作。
- 同一资料连续三次解析失败后，卡片变为“仅链接 / 仅附件”状态，保留手动重新解析入口；该状态不参与搜索、RAG 或引用。

### 5.3 右侧 AI 对话区

- 顶部：`AI 对话` 标题、右侧新建会话和历史按钮、底部细分隔线。
- 空状态：在大面积留白的视觉中心展示“从你的资料里找答案”，使用淡灰蓝常规字重；不显示补充说明文案。
- 不使用空状态图标。
- 对话消息沿用深色用户消息气泡与浅色回答文本，引用显示为小型描边标签。

### 5.4 知识库 AI 输入区

- 固定在右侧 AI 区底部，以一根顶部细线与对话内容分隔。
- 无外框、无大圆角、透明背景；保持页面乳白底与右下粉色环境光。
- 提示语：`基于当前知识库进行提问`，颜色为淡灰蓝。
- 底部只保留可展开的 `# 标签` 选择器；不显示加号、链接按钮或知识库选择器。
- 标签可选：标签、增长策略、用户研究、产品灵感。
- 发送按钮为 40px 深色圆角方形，白色向上箭头；不使用白色晕染外圈或流动描边。

## 6. 笔记与灵感卡片

### 6.1 笔记工作台布局

- “笔记”使用左侧全局导航之外的双栏工作台：顶部仅页面标题「笔记」（**无**「个人记录」eyebrow）、`我的笔记 / 灵感卡片` Tab，右上角黑色「新建笔记」主按钮与标题文字底边水平对齐。
- 整体密度偏紧凑：减小页头、Tab、列表与编辑区 padding，避免内容区偏右、偏下。
- 此布局只参考已确认截图的空间结构与操作层级，不参考其深色配色、米色背景、字体或组件样式；所有表面、字体、按钮和分隔线继续沿用本文既有 Refind 设计语言。
- 顶部标题区、Tab 区与内容区以低对比细线分隔；列表栏与编辑主区之间使用贯通的垂直细分割线，不添加大卡片外框。
- 右侧主区留出充分的阅读与写作宽度；未打开内容时的引导居中但克制，不使用空状态插画或大面积卡片。

### 6.2 我的笔记

- 列表栏工具行：**缩小后的笔记本下拉** 与 **搜索笔记** 同一行；其下为按“最近编辑 / 更早”分组的笔记列表。
- 笔记本筛选默认“全部笔记”；它是轻量菜单入口而非固定树状侧栏。菜单底部可提供“管理笔记本”。
- 笔记项以标题为主、最后编辑时间为次要信息；列表不显示笔记同步到的知识库或绑定的灵感卡片。
- 选中笔记使用与全局导航一致的轻玻璃高亮，不使用强色块；右键触发的操作使用紧凑浮层。
- 右侧主区顶部常驻紧凑富文本工具栏；「已保存 / 正在保存」**左侧**提供全屏编辑 icon。正文为无边框自由编辑画布。
- 「我的笔记」与「灵感卡片」为独立入口；灵感卡片只服务创作笔记，不是第二套笔记库。

### 6.3 灵感卡片

- 灵感卡片 Tab 的主内容为卡片列表，而不是右侧常驻预览面板或瀑布流；卡片保持克制的列表密度，突出摘录文本、来源标记与收藏时间。
- 工具栏：**去掉筛选**；搜索栏延伸至「整理为笔记」按钮之前。
- 页头的“整理为笔记”是稳定主操作；默认浏览态不出现复选框，进入选择态后才在列表行前出现复选框与已选数量。
- **选择条（已确认）：** 内嵌圆角长条（约 `12px`），左右与卡片区对齐，**非**通栏贴边；底色为左浅右深弱渐变 `#EEEEED → #E9E9E8 → #E8E8E7`。
- 点击单张卡片时使用居中详情弹窗，呈现摘录内容、原问题、回答模式、来源和引用信息；通用 AI 卡片以文字标签区分，不能伪装成知识库引用。

### 6.4 全屏笔记编辑页

- 全屏时隐藏笔记列表与全局侧栏，形成完整写作画布；顶部使用单行轻量工具栏（返回、保存状态、撤销/重做、富文本工具等）。
- **素材面板规则（已确认）：**
  - 「新建笔记」（任一 Tab）→ 全屏，**不显示**素材面板与「生成笔记」。
  - 「整理为笔记」勾选卡片进入 → 全屏，**显示**底部素材面板与「生成笔记」。
  - 双栏内点全屏 icon → 若该笔记已有灵感素材则 **显示**素材面板；否则不显示。
- 全屏返回后切到「我的笔记」，列表选中该笔记。
- 素材面板固定在编辑页底部；面板展开时展示可排序素材与“我的想法”，收起后正文恢复完整宽度。
- AI 生成后的正文直接呈现在同一编辑画布内；资料型引用为句末内联小型 `[n]` 标记（不写「（来源：）」），并绑定灵感卡片。
- **笔记引用预览（已确认）：** hover `[n]` 展开预览菜单（来源、摘录、问题、回卡片提示）；点击打开灵感卡片详情；菜单贴边时右对齐/向左展开，不得超出视口。

## 8. 交互与状态

- 知识库导航：点击知识库默认选中“默认知识库”。
- 侧栏知识库列表：当前项使用轻玻璃高亮，非强色块高亮。
- 筛选、标签、知识库选择与会话历史均为可点击展开菜单；**点击外部区域或 Esc 关闭**。
- 资料搜索、知识库新增、AI 提问、保存 AI 回答、账号菜单均已具备 Demo 交互。
- AI 回答中，划选文字后在选区旁展示小型收藏工具条；每条回答末尾固定展示 **复制 → 收藏 → 分享 → 更多**。更多菜单容纳删除与反馈等次级操作。
- 点击收藏后展示轻量菜单：`保存为灵感卡片`、`加入笔记`；菜单锚定触发器并以页面顶层浮层呈现。
- 点击分享后进入选气泡；底栏替换为分享栏；复制对话链接成功后自动退回对话输入。
- 点击已有笔记后，右侧主区直接载入可编辑正文，但不自动聚焦光标；新建笔记立即在列表创建并选中“未命名笔记”，右侧展示独立标题输入与空白正文。
- 灵感卡片默认按收藏时间从新到旧展示；搜索覆盖摘录和原问题。详情弹窗以“加入笔记”为主操作，查看原对话、复制和删除收进更多菜单。
- 点击“整理为笔记”后，出现内嵌圆角选择条（左浅右深弱渐变），展示“已选 X 张”、取消与开始整理；素材按当前卡片列表顺序带入编辑页。添加卡片采用多选弹窗，确认后追加至素材面板末尾。
- 素材为空时“生成笔记”置灰并解释原因；每张卡片的“我的想法”默认收起，点击后展开自动增高输入区。
- 生成期间按钮显示“生成中”，保留原正文、暂时禁止编辑；成功后替换正文并滚回开头，素材面板维持当前开关状态；失败时保留正文与素材并提供重试。
- **对话区**来源编号在桌面端 hover 时显示资料浮卡，点击后固定展开。**笔记正文**内联 `[n]` hover 显示灵感卡片预览菜单，点击打开卡片详情（须夹取视口）。笔记同步多个知识库时采用非阻塞进度提示，并提供逐项失败重试。
- 删除笔记前提示其会连带删除的同步资料数量；删除灵感卡片前提示受影响笔记数，确认后仅从相关素材面板移除，不改变已生成正文。
- 支持 `prefers-reduced-motion`，需要动效时应有静态降级状态。

## 9. 后续变更约束

- 新增页面或组件应复用本文的颜色、字体、分割线和圆角层级。
- 未经明确确认，不将笔记工作台改为卡片瀑布流、固定笔记本树或右侧常驻卡片预览；全屏灵感编辑页不显示全局导航。

## 10. 2026-09-13 设计修订（已确认）

### 10.1 已落地视觉 / 框架

- **全宽工作台**：取消 1200px 左对齐安全区上限；壳层拉满视口，侧栏 + 内容按比例分配。
- **黑色强调**：拾藏主操作与折叠钮以黑色为主；蜜桃粉环境光降为可选弱氛围，不得压过内容层级。
- **侧栏**：边缘半出圆形折叠钮（黑底白 chevron）；知识库导航为文件夹图标；展开约 220px，平板图标轨，手机抽屉。
- **知识库页**：资料列与 AI 列竖分割线上下贯通；标题约 24px；工具行：搜索、筛选、添加资料（同行）；资料列表顶部紧凑排列（`align-content: start`）。
- **知识库 AI 输入**：通底细分隔线；DeepSeek 模型芯片；输入 `#` 时标签建议 **向上** 弹出。
- **首页 composer**：`DS快速`/`DS深度`、联网、多选知识库并集、`#` 标签 AND；黑色圆发送钮；Enter 发送。
- **首页对话壳**：`hero`/`chat`；历史浮动卡 `#FCFCFB`；对话区滚动隐藏滚动条；composer 钉底。
- **分享栏**：替换 composer；文案「已选择 N 条气泡」；主按钮 `#111` + 10px 圆角；次按钮 `#FDFDFD` + `#E2E4E7`；复制成功自动退出。
- **选气泡**：左侧平面勾选圈（选中实心 `#111`）；未选弱化；禁止亮蓝整块染色。
- **回答菜单**：portal / fixed，`z-index: 10000`，高于一切壳层控件。
