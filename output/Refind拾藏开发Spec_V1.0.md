# 1. 文档目的与实现范围

本文档将 Refind V1 的已确认产品规则转化为开发规格，覆盖 Web 端页面、服务端能力、数据模型、状态流转、接口约束和验收标准。

## 1.1 产品目标

Refind 是面向工作、学习与研究场景的 AI 个人知识助手。用户将网页或社媒链接保存至知识库，系统完成内容解析、AI 摘要与标签生成；用户可通过关键词找回资料，并基于已保存资料进行 RAG 对话和查看回答来源。

## 1.2 V1 边界

### 本期实现

- 邮箱与密码注册、登录、忘记密码、退出登录、注销账户；
- 多知识库、默认知识库、资料添加、编辑、移动和删除；
- 链接、图片、PDF、DOC/DOCX、Markdown、TXT、PPTX、XLSX、CSV 资料导入与解析；
- 注册时填写用户名，写入 `profiles.display_name`，侧栏展示真实用户名；
- 支持连接的小红书、抖音、知乎、B 站、微信公众号账号（可选，用于提升受限平台解析成功率）；
- 用户以受控浏览器完成平台登录，平台会话加密保存并按 Refind 用户隔离；
- **主流受限平台**以 MediaCrawler + 平台适配器解析；**其他网页**以匿名抽取解析（无需用户在目标站注册）；
- AI 摘要、标签、向量索引、关键词资料搜索、RAG 对话、来源引用；
- 多会话管理、主动生成脑图和新增资料标记。

### 本期不实现

- 邮箱验证；
- 手机号登录、第三方登录；
- 多个同平台账号连接；
- 评论区入库；
- 视频语音转写（ASR）；
- 要求用户为「搜到就藏」的长尾网站逐一注册或连接；
- 复杂 Agent；
- 团队协作、共享知识库、知识图谱和通知中心。

# 2. 总体架构与模块边界

```text
Web 客户端
├── 认证：注册 / 登录 / 忘记密码 / 注销
├── 知识库：列表 / 创建 / 编辑 / 删除 / 资料列表
├── 资料导入：链接与文件上传 / 平台识别 / 直接入库 / 后台解析
├── 设置：账户与安全 / 连接内容平台
├── 搜索：知识库关键词搜索 / 资料关键词搜索 / 搜索建议浮层 / 来源筛选
└── AI 对话：会话列表 / RAG 问答 / 来源引用 / 脑图

服务端
├── 认证与访问控制
├── 关系数据与对象存储：Supabase Postgres
├── 向量检索：pgvector
├── 内容解析编排：
│     ├── 主流平台适配器（MediaCrawler）
│     └── 通用网页匿名抽取（Crawl4AI / Readability 类；必要时 Playwright 匿名渲染）
├── 平台会话管理：加密保存、失效检测、受控浏览器连接（仅五个主流平台）
├── AI 编排：DeepSeek Chat + text-embedding-v4
└── 异步任务：链接与文件解析、AI 结构化、索引更新、脑图生成
```

## 2.1 关键技术约束

- Refind 数据通过 `user_id` 严格隔离；所有数据库查询、对象访问和接口均需校验当前登录用户。
- 首页默认使用 DS（DeepSeek）模型进行普通任务对话，可由用户选择联网或不联网；选择任意知识库或资料标签即切换为严格 RAG，并强制关闭联网。知识库模块内的 RAG 回答仅使用当前用户、状态为 `ready` 的资料片段和当前会话上下文；不得联网补充知识库外信息。
- 每个平台解析适配器独立实现，统一返回标准化内容结构；解析器失败不得阻塞“仅保存链接”兜底。
- MediaCrawler 仅用于五个主流受限平台的内容读取，不直接决定 Refind 的用户、知识库或资料归属。
- 非主流 / 搜索引擎搜到的长尾网页一律按**匿名访客**抓取，不得要求用户在目标站注册或建立「站点连接」。

# 4. 认证、账户与权限

## 4.1 注册与登录

| 功能 | 规则 |
| --- | --- |
| 注册 | 邮箱 + 密码 + **用户名**（写入 `profiles.display_name` 与认证 metadata）。注册成功后直接创建会话，不要求验证邮箱。 |
| 默认知识库 | 注册事务成功后自动创建一个 `default` 知识库，初始名称为“默认知识库”。 |
| 登录 | 邮箱 + 密码。 |
| 忘记密码 | 发送密码重置链接至注册邮箱；用户通过链接设置新密码。 |
| 退出登录 | 清除当前 Refind 会话，不删除云端数据及平台连接。 |

## 4.2 注销账户

入口位于设置页“账户与安全”。用户点击注销后必须二次确认，确认文案需明确“账户、知识库、资料、AI 对话、脑图和平台连接均将永久删除，且不可恢复”。

确认后执行原子清理或受控异步级联清理：认证账户、资料正文、标签、资料片段、向量、知识库、会话、消息、引用、脑图、导入任务、笔记本、笔记、灵感卡片、笔记素材关系、笔记修订和加密平台会话均永久删除。任何删除失败均不得显示“注销成功”。

## 4.3 权限规则

- 所有业务接口必须验证已登录身份。
- 用户只可访问 `user_id` 等于当前身份的资源。
- 平台会话的密文不可经由客户端接口读取、下载或返回。
- 用户只能连接、重连或断开自己的平台账号。

# 5. 页面与交互规格

## 5.1 应用外壳

登录后采用一级导航：**首页 / 笔记 / 知识库**（首页与知识库并列，非「登录即三栏知识库工作台」）。

- **首页**：欢迎区 + 全局 AI；可通用对话或选范围后严格 RAG。
- **知识库**：中部资料列表 + 右侧当前库 AI。
- **笔记**：笔记 / 灵感工作台。

左侧区域从上至下为：产品标识、主导航、**知识库搜索框、知识库列表**（在首页/笔记/知识库均常显）、底部用户账户触发区。知识库导航项旁提供新建加号。

### 知识库列表进入规则（2026-09-15）

- 点击导航「知识库」：进入知识库页，自动选中列表第一条（优先默认库），右侧加载资料。
- 直接点击某一知识库：进入知识库页并选中该项。
- 未处于知识库页时：列表不显示选中高亮；搜索仍可用。
- 知识库名搜索无结果：「未找到符合条件的知识库」。

用户账户触发区显示用户名首字母头像和用户名；点击后打开「设置 / 退出登录」（注销仅在设置「账户与安全」）。

首页不提供全局「添加资料」入口。添加资料始终在当前选中知识库中进行。

### 视觉实现约束

- 唯一视觉基准为 `/Users/zoecheng/.codex/generated_images/019ff51d-efe2-78b0-8875-b174eec26729/exec-9588f1f2-ccd1-4ef2-bc8c-57172aedfcb3.png`；后续开发、还原和视觉验收均以该图为准（布局后续已确认为全宽工作台，见设计文档 §10.1）。
- 全局导航展开态约 220px，提供折叠按钮；收起态仅保留图标，隐藏导航文字、知识库列表和账号文字，并通过 tooltip 或等价可访问名称解释图标。
- `≥1200px` 保留桌面多栏工作台；`768–1199px` 使用紧凑双栏，导航默认图标态，AI 对话、筛选和素材面板为覆盖式面板；`<768px` 使用单栏和左侧导航抽屉。
- 移动端触控目标不得小于 44px；不得通过缩放桌面多栏来伪适配移动端。
- 组件采用扁平风格：圆角 8–12px、低对比细边框、无或极浅阴影。默认页不展示菜单、筛选、引用或账户等弹层；弹层仅由用户操作触发。
- 「新建知识库」加号自定义 hover 提示须右对齐，避免侧栏裁切；不叠原生 `title`。

## 5.2 知识库列表与管理

### 展示

- 显示知识库名称、创建时选定的预设图标、资料数量和当前选中态；
- 默认知识库始终显示，不可删除；
- 自定义知识库按最近更新时间倒序；默认知识库固定在列表顶部；
- 空资料知识库仍显示，资料数为 0。

### 创建与编辑

| 项目 | 规则 |
| --- | --- |
| 名称 | 必填，1–30 字，去除首尾空格。 |
| 简介 | 选填，最多 100 字。 |
| 图标 | 必填，从系统预设图标中选择；系统仅保存图标标识，客户端按标识渲染。 |
| 同名 | 同一用户内禁止重名；创建/重命名时提示“已有同名知识库，请修改名称”。 |
| 创建成功 | 新知识库在左侧新增并自动选中；右侧显示空资料列表和“添加第一篇资料”引导。 |
| 默认知识库 | 可改名，不可删除。 |

### 删除自定义知识库

用户点击删除后展示二次确认：确认将永久删除该知识库及其全部资料，无法恢复。确认后删除知识库及其资料正文、摘要、标签关系、资料片段、向量索引；历史会话保留，但涉及该资料的引用显示“该资料已删除”。

## 5.3 当前知识库资料列表

### 资料卡片

卡片显示：预览图、标题、来源平台、单行截断摘要、资料标签、创建时间、状态和新增标记。创建时间固定在卡片右上角；来源平台标签固定于卡片右侧，使用“小圆点 + 平台名称”格式。

- `ready`：正常卡片；
- `link_only`：展示“待补充内容”状态，不展示摘要和正文节选；
- `is_new=true`：卡片展示新增标记；用户点击进入详情后，标记立即消失；
- `processing`：出现在资料列表底部，在来源/标签位置展示“解析中”、圆形进度与百分比；
- `failed`：保留在资料列表，展示失败原因、重新解析和删除。

### 排序

默认“时间：从新到旧”。支持：

- 时间：从新到旧 / 从旧到新；
- 标题：A–Z / Z–A；

排序浮层按“时间”“标题”两组展示；每次仅选择一种排序规则。默认时间从新到旧；切换至标题排序时，标题组默认规则为 A–Z。

### 来源平台筛选

- 资料区提供单选来源平台筛选，选项为“全部来源、小红书、抖音、微信、知乎、B 站、其他”；默认“全部来源”。每一项按“平台小圆点 + 平台名称”展示；
- 来源筛选、资料关键词搜索与排序为 AND 关系：先限定当前知识库，再同时应用关键词匹配和来源条件，最后按所选排序规则输出；
- 切换筛选后即时刷新资料列表；无结果时展示空状态，不自动清空已输入的关键词。

## 5.4 添加资料

### 入口与归属

用户只能在当前选中的知识库点击“添加资料”。该资料的归属知识库在导入过程中不可修改；如需变更，保存后通过“移动资料”处理。

### 链接与文件处理流程

```text
点击“添加资料” → 选择“粘贴链接”或“上传文件”
→ 链接校验或文件上传 → 立即创建资料卡片并归属当前知识库
→ 后台解析、摘要、标签、切片与向量化 → `ready`
```

支持 `链接、图片、PDF、DOC/DOCX、Markdown、TXT、PPTX、XLSX、CSV`。一次可加入多个文件；不提供解析结果预览和人工确认保存步骤。链接提取正文，图片执行 OCR 与视觉描述，其他文件按其可读文本/表格/幻灯片内容解析；成功资料均生成摘要、标签和检索切片。新资料**不默认写入 `#待整理`**；仅用户或解析器实际产出标签时展示。

对象存储键仅使用 `userId/uuid.ext`（不含原始文件名中的空格、`+`、中文等），避免 Storage `Invalid key`。

### 平台识别及链接解析分流

支持识别：小红书、抖音、知乎、B 站、微信公众号、普通网页和其他链接（按 URL hostname 推断 `platform_code`）。

```text
粘贴链接 → 识别 platform_code → 立即创建资料卡片（processing）
├── 主流平台（xhs / douyin / zhihu / bilibili / wechat_mp）
│     └── MediaCrawler + 可选用户平台会话
│           ├── 已连接：优先用该会话解析
│           ├── 未连接：仍尝试公开可达解析；需要会话时提示「去连接」或「仅保存链接」
│           └── 失败累计 → link_only
└── 其他网页（web / other，含搜索引擎搜到的长尾站）
      ├── 匿名抽取（Crawl4AI / Readability 等）← 默认
      ├── 强 SPA 可选用 Playwright 匿名渲染（仍不要求用户登录目标站）
      └── 失败累计 → link_only（可重试 / 粘贴正文 / 上传文件补充）
```

规则摘要：

- **其他网页**：一律匿名访客抓取；**禁止**要求用户在目标站注册或建立通用「站点连接」；
- **主流平台连接为可选增强**：提升登录墙内容的解析成功率，不是「搜到就藏」的前置条件；未连接也须允许保存链接并进入解析/降级链路；
- 已连接：使用该用户对应平台的加密会话解析；
- 平台会话失效：显示“{平台名}登录已失效，请重新连接后继续解析”，提供“重新连接”和“仅保存链接”；重新连接成功后自动继续当前链接解析；
- 公众号：优先直接/匿名解析；访问受限时再提示连接微信。

### 解析状态与界面反馈

“添加资料”按钮旁显示失败/降级等 toast；处理中状态以资料列表行展示为主，避免进度浮窗长期挤占工具栏。资料卡片在用户确认添加后**立刻**出现在列表（乐观 `processing`）；成功后平滑替换为来源平台与标签。列表类型展示：链接显示平台名或「链接」；文件显示 PDF / Word / PPT / Excel 等。用户离开页面后后台任务继续，V1 不提供通知中心。

知识库侧栏列表与资料列表均须支持上下滚动；滚动条隐藏，保留滚轮/触控滑动。

### 内容入库范围

| 内容 | V1 规则 |
| --- | --- |
| 普通 / 长尾网页 | 标题、来源、正文/节选、原链接及可获得元数据（匿名抽取）。 |
| 小红书图文 | 标题、作者、发布时间、正文说明、话题标签、原链接及可获得的图片说明/文本。 |
| 抖音视频 | **播放**：应用内嵌播放（不落盘视频文件）+「在原站打开」。**正文** `content_text` = 文案 + 已有字幕（无则仅文案）。**摘要** 基于正文由 AI 生成。另入库标题、作者、发布时间、话题标签、原链接。无 ASR、无评论。 |
| B 站视频 | 与抖音相同（优先官方 embed；临时直链可作兜底）。 |
| 知乎、公众号 | 标题、作者/账号、正文或可用文本、发布时间、原链接及可获得标签。 |
| 评论区 | 所有平台均不入库。 |
| 图片 | OCR 提取可识别文字，并生成用于检索的视觉内容描述（**V1 范围内**）。 |
| PDF、DOC/DOCX、Markdown、TXT | 提取可读文字与文档结构。 |
| PPTX、XLSX、CSV | 提取幻灯片或表格中的可读内容并结构化为检索文本。 |

### 失败与兜底

- URL 非法或文件不受支持：不创建资料，提示具体原因；
- 解析失败：资料卡片保留，展示失败原因并提供“重新解析”和“删除”；
- 同一资料连续三次解析失败后，自动降级为 `link_only`（链接）或 `attachment_only`（文件），保留原链接/附件但不参与搜索、RAG 检索和来源引用；
- 降级资料仍永久提供“重新解析”，任一次成功后进入 `ready` 并建立索引；
- 用户删除失败卡片时，永久删除该资料和附件对象。

## 5.5 资料详情、编辑、移动与删除

### 详情

显示标题、知识库、来源平台、保存时间、原始链接、摘要、标签、主体文本/节选及资料状态。抖音/B 站另展示可点播播放器（见 §12.2）。提供查看原文、编辑、移动、重新解析（`link_only` 必显）和删除入口。

### 编辑与索引更新

| 编辑项 | 保存后动作 |
| --- | --- |
| 标题、摘要、主体文本 | 后台重新切片并生成向量；更新期间继续使用旧索引，完成后原子切换。 |
| 标签 | 立即更新标签关系并影响 #标签过滤。 |
| 所属知识库 | 通过“移动资料”变更；立即更新资料及全部片段的知识库归属。 |

### 移动

用户可移动至任意知识库，包括默认知识库。目标知识库选择列表仅展示当前用户的知识库；移动后资料不复制，原知识库不再保留该资料。

### 删除资料

删除需二次确认。确认后永久删除资料、摘要、标签关系、切片与向量索引。历史会话保留问题与回答，但对应引用显示“该资料已删除”，不可查看原文或原文片段。

## 5.6 搜索建议浮层

### 入口

- 知识库搜索：左侧知识库导航，按知识库名称做关键词匹配；
- 资料搜索：当前知识库资料区，按当前知识库的 `ready` 资料标题、摘要和标签做关键词匹配。

### 行为

- 用户输入关键词后发起本地关键词匹配；关键词按标题、摘要、标签的命中情况计算展示顺序；
- 输入为空时不显示浮层；
- 搜索中显示加载状态；
- 有结果时展示标题、所属知识库、匹配片段、标签、来源平台；
- 无结果时显示“未找到相关资料”；
- 点击结果进入资料详情；点击空白区域或关闭按钮关闭浮层；
- `link_only`、已删除和非当前用户资料绝不可返回；
- 资料搜索不调用 Embedding、pgvector 或 RAG；AI 对话检索规则不受本节影响。

## 5.7 笔记与灵感卡片

### 笔记工作台

- 全局一级导航保持“首页、笔记、知识库”；点击“笔记”进入笔记工作台；
- 页头仅展示标题「笔记」（无「个人记录」eyebrow），顶部提供“我的笔记 / 灵感卡片”切换，右上角黑色「新建笔记」与标题底边水平对齐；布局保持紧凑，避免内容区偏右下；
- 「我的笔记」与「灵感卡片」为独立入口；灵感卡片仅用于创作笔记；
- “我的笔记”列表栏工具行为同一行：缩小后的「全部笔记 / 各笔记本」下拉 +「搜索笔记」；其下按“最近编辑 / 更早”等时间分组；
- 笔记本下拉菜单提供“管理笔记本”。管理弹窗支持新建、重命名和删除；删除时必须 alert 二次确认，并可选择“仅删除笔记本，笔记转为未归类”或“连同其中全部笔记永久删除”；后一选项须提示删除笔记数及同步资料的连带删除；
- 右侧主区为富文本编辑工作区，顶部含编辑工具栏；「已保存 / 正在保存」左侧提供全屏编辑入口；点击已有笔记后直接加载正文但不自动聚焦光标；
- 「新建笔记」（任一 Tab）立即创建「未命名笔记」并进入 **全屏** 编辑，**不显示**素材面板与「生成笔记」；返回后切到「我的笔记」并选中该笔记；
- 笔记列表项可右键操作：加入/移动笔记本、添加至知识库、查看或移出已同步知识库、删除；添加至知识库可多选目标知识库。
- 笔记列表不显示笔记同步到了哪个知识库，也不显示其绑定了哪些灵感卡片；这些信息仅在右键菜单或编辑页按需查看。

### 富文本编辑与自动保存

- 编辑器采用所见即所得富文本体验，底层保存 `rich_text_json`，不要求用户书写 Markdown；
- V1 工具栏提供：撤销、重做、标题层级、粗体、斜体、下划线、删除线、文字颜色/高亮、对齐、无序/有序列表、引用、链接、代码块和分割线；
- 任意输入、格式调整、素材调整或 AI 写入停止约 1–2 秒后自动保存；离开编辑页与生成前后立即保存；顶部反馈“正在保存 / 已保存 / 保存失败，可重试”；
- 编辑器提供类似 Word 的撤销/重做按钮，覆盖普通编辑、格式变更、AI 写入与素材变更；
- 从“新建笔记”进入时不显示素材面板或“生成笔记”，仅提供自由富文本写作。

### 灵感卡片收藏与管理

- 用户可在 AI 回答中划选任意片段并收藏，也可收藏整条回答；收藏时可选择“保存为灵感卡片”或“加入笔记”；
- “加入笔记”支持新建笔记或选择已有笔记，卡片加入后仅作为素材，不自动改写正文；
- 灵感卡片默认按收藏时间从新到旧展示；搜索匹配卡片摘录与原问题；**原型本迭代去掉来源/时间筛选入口**，搜索栏延伸至「整理为笔记」之前；点击卡片打开详情弹窗；
- 卡片详情以“加入笔记”为主操作；查看原对话、复制和删除收纳在更多菜单；
- 页头始终显示“整理为笔记”。默认浏览态不显示复选框；点击后列表进入选择模式，显示复选框、内嵌圆角选择条（左浅右深弱渐变 `#EEEEED → #E9E9E8 → #E8E8E7`）、已选数量、取消和“开始整理”，未选择卡片时不得开始；
- 开始整理后立即创建笔记并打开全屏编辑页，所选卡片按当前卡片列表顺序进入底部素材面板；卡片可重复用于多篇笔记，移除素材或删除笔记不删除卡片库。
- 删除正被笔记使用的灵感卡片前，必须提示受影响笔记数；确认后从这些笔记的素材面板移除卡片，但不改变已生成的笔记正文。

### 灵感笔记编辑与生成

- 全屏编辑入口分流：
  - 「新建笔记」→ 全屏，无素材面板、无「生成笔记」；
  - 「整理为笔记」→ 全屏，有素材面板与「生成笔记」；
  - 双栏「已保存」左侧全屏 icon → 若笔记已绑定灵感素材则显示素材面板（及生成能力），否则同空白全屏；
- 全屏返回 →「我的笔记」Tab，并选中该笔记；
- 从灵感卡片整理进入的编辑页为全屏富文本编辑器；顶部包含返回笔记、自动保存状态、撤销/重做、完整富文本工具、添加灵感卡片、素材面板开关与唯一的“生成笔记”按钮；
- 底部素材面板可收起；打开时展示可拖拽排序的卡片、每卡可选“我的想法”、移除操作与“添加卡片”；“我的想法”默认收起，点击后展开自动增高输入区；添加卡片打开多选选择器，确认后追加至素材面板末尾；
- 素材为空时“生成笔记”必须禁用并说明原因；点击后按钮显示“生成中”，保留原正文但暂时禁止编辑；AI 仅根据当前卡片内容、排序与“我的想法”生成新正文，并在同一编辑页替换正文；每次生成前后台创建 `note_revision`，不另设“草稿 / 发布”概念；成功后滚至正文开头并保持素材面板当前开关状态；失败时保留正文与素材并提供重试；
- RAG 卡片生成的关键结论自动写入可交互内联 `[1]`、`[2]` 等标记（绑定 `cardId` 与引用标签快照），**不**附加「（来源：）」纯文本；通用 AI 卡片不得伪造资料引用，仅在素材面板标识“通用 AI 回答”并允许回到原对话；
- **Hover** `[n]` 展开预览菜单（来源标签、卡片摘录、原问题、「点击查看灵感卡片」）；**点击**角标或菜单打开灵感卡片详情弹窗；预览菜单须夹取视口（贴右缘时右对齐并向左展开）；
- 用户可随时编辑 AI 正文；素材面板收起后保留完整自由编辑器。

### 笔记与知识库的多库同步

- 一篇笔记可添加至多个知识库，每个目标知识库生成一篇 `origin_type=note` 的同步资料；
- 编辑笔记时，系统将标题与正文同步到所有关联资料并触发各自索引更新；在任一知识库编辑同步资料时，系统先更新原笔记，再同步到其余全部关联资料；
- 删除某个知识库或其中的同步资料，只解除该知识库的关联，不删除原笔记或其他知识库的同步资料；
- 删除笔记时，必须永久删除其在全部知识库中的同步资料及关联索引。
- 添加至知识库的多选确认后，以非阻塞状态提示“正在同步至 X 个知识库”；完成后显示成功数量，个别失败时列出失败项并提供重试。

## 5.8 AI 对话

### 会话管理

- 对话区固定在工作台右栏，包含“新建会话”按钮与仅图标的历史会话入口；首页另有左侧可折叠历史会话卡；
- 会话按 `surface`（`home` | `knowledge`）与可选 `knowledge_base_id` 分面持久化；首页历史与各知识库历史互不混入；
- 会话列表按最近更新时间倒序；点击可查看并继续该会话；
- 「新建 / 新增会话」立即插入草稿（标题「新会话」）并出现在对应历史列表；不复制上一会话上下文；
- **进入知识库页或切换知识库：** 加载该库会话列表后，默认选中并展示最新一条（按 `updated_at`）；无历史则空态；
- 首条用户问题发送成功后，若标题仍为占位文案，则用该问题截断更新标题；
- 支持右键内联重命名（无弹窗：回车/失焦保存，Esc 取消）；
- 删除会话需二次确认，确认后永久删除该会话下的消息、引用与脑图；
- 首页只选 **1** 个知识库提问时，会话写入该库的 `knowledge` 历史；多选知识库或仅标签仍记 `home`；知识库面板提问始终记当前库。

### 回答收藏与快捷操作

- 用户划选 AI 回答文字时，在选区旁显示小型浮动工具条，用于收藏该精确片段；
- 每条 AI 回答末尾固定展示操作图标，顺序为：**复制 → 收藏整答 → 分享 → 更多**；更多菜单包含删除、反馈等次级操作；
- 片段或整答收藏均先弹出轻量菜单「保存为灵感卡片 / 加入笔记」；菜单锚定于收藏触发器旁，并以页面级浮层呈现（不得被输入框或滚动容器裁切）；
- 选择加入笔记时，用户可新建笔记或选择已有笔记。

### 分享选气泡（首页对话）

- 点击「分享」进入选气泡模式：用户气泡与回答气泡均可勾选；默认选中触发分享的那条回答；
- 选气泡时左侧使用平面勾选圈（选中为实心黑），未选气泡视觉弱化；
- 底部 composer **整块替换**为分享栏：「已选择 N 条气泡」+「复制对话链接」+「取消」；
- 「复制对话链接」成功后提示已复制，并自动退出分享模式、恢复 composer；
- 「取消」、新建会话、切换历史会话或离开首页均退出分享模式。

### 提问与 #标签

- 用户可输入自然语言问题；
- 首页输入框展示模型选择器（默认 DeepSeek，芯片文案 `DS快速` / `DS深度`）、联网/不联网开关、多选知识库选择器；标签通过输入 `#` 上拉选择（可不提供独立 `@标签` 按钮）；不提供上传资料加号；
- Enter 发送，Shift+Enter 换行；发送钮为黑色圆形；
- 一个会话内模型、联网状态、知识库范围与标签范围持续生效，直到用户主动修改或新建会话；
- 选择多个知识库时按并集检索；多个标签按 AND 关系筛选；仅选择标签而未选择知识库时，在用户全部知识库中按标签检索；
- 支持一个或多个 `#标签`，仅匹配资料标签，不匹配知识库名称；
- 多个标签使用 AND 关系；
- 未使用标签时，检索用户全部可用知识库；
- 标签不存在或范围内无相关资料时，提示当前范围无相关资料，不自动扩大检索范围。

### 首页通用 AI 与 RAG 回答

- 首页未选择知识库或标签时为通用 AI，可按联网开关使用模型通用能力；该模式的回答不显示知识库资料数量或伪造资料引用；
- 首页选择任意知识库或资料标签后切换为严格 RAG，联网开关立即禁用并以“不联网（知识库模式）”说明原因；知识库模块的 AI 对话始终为严格 RAG；
- 严格 RAG 模式只使用用户可访问的 `ready` 资料片段和当前会话上下文，不联网、不使用知识库外信息。

```text
保存/编辑资料 → 文本切片 → Embedding 向量化 → pgvector 索引
用户提问（RAG）→ 解析 #标签 → 标签过滤
  → 并行：问题向量召回 + 关键词/标题召回（各 ~20）
  → RRF 融合（≤40）→ 按 material_id 多样性（≤3）
  → 百炼 qwen3-rerank（floor 0.4；失败则 light rerank）
  → topK≈8（运维 6–10）进 prompt → DeepSeek → 保存消息与 [n] 引用
  → 过弱 / 无有效引用 → 「暂无相关资料」（可跳过 LLM）
```

严格 RAG 回答区必须：

- 只使用召回片段和当前会话上下文；
- 每个关键事实、观点、案例或结论附句末 `[n]` 来源标记（不要文档名、不要末尾汇总列表）；
- 对资料间冲突说明差异并分别引用；
- 对推断使用明确的推断表达，不将推断写成既有事实。

消息呈现规则：用户消息右对齐，以气泡呈现；AI 消息左对齐，以无卡片容器的紧凑分段/列表文本呈现。双方均不展示头像。首页通用 AI 回答不显示严格 RAG 的资料计数与来源引用。首页对话列（含输入框）在历史展开/折叠时左右外边距保持一致。

### 严格 RAG 的资料不足

满足以下任一条件时，回答标记 `is_insufficient=true`：无召回资料、rerank 后相关性过弱、模型输出无有效 in-range `[n]`。

资料不足统一文案：**`暂无相关资料`**；检索过弱时服务端可不调用 LLM。不得给出无依据的完整结论。

### 严格 RAG 的来源引用

每条关键结论在句末以 `[1]`、`[2]` 等引用编号关联对应资料。点击引用编号打开引用浮卡（portal + 高 z-index，避开 sticky composer），展示资料标题、摘录和查看原文入口。资料已删除时，卡片仅显示“该资料已删除”，不得暴露已删除内容。

## 5.9 一键生成脑图

- 入口位于单条 AI 回答底部；
- 仅当回答不是资料不足、且包含可组织的层级内容时显示“生成脑图”；
- 用户主动点击后创建异步生成任务；
- 脑图仅基于本轮回答及其已引用资料生成；
- 脑图以问题或回答主题为中心节点，展示核心结论、子观点、案例或行动建议；
- 节点可展开、收起；有来源依据的节点展示引用标记；
- 生成成功后保存至当前会话；再次打开该会话可查看；
- 生成失败显示“脑图生成失败，请重试”，不得影响原回答。

## 5.10 设置模块

入口位于左侧导航底部的用户账户触发区菜单内（菜单项：设置 / 退出登录）。

### 账户与安全

- 展示当前邮箱；
- 编辑展示用户名（`profiles.display_name`）；
- 修改密码（校验当前密码后更新）；
- 注销账户（二次确认；账号菜单不提供注销入口）。

### 连接内容平台

#### 目标行为（V1 完整）

- 每个平台仅允许连接一个账号；更换账号需先断开；
- 点击连接后，在 Refind 受控浏览器中由用户自行完成扫码、验证码或平台登录；
- 登录成功后，服务端加密保存平台会话；
- 断开连接需二次确认；断开后保留已导入资料，仅停止后续解析；
- 连接页面和粘贴未连接链接时均可触发连接流程；
- 粘贴链接触发连接后，成功连接应自动返回并继续该链接解析。

#### 当前实现边界（2026-09-15 · 阶段 A）

- UI + `platform_connections` 读写已落地；连接写入**演示态**会话标记，**非**真实平台登录；
- 已连接时解析预取可带 `use_saved_session`（优先本机 Cookie）；
- 真实扫码登录（B）与托管解析服务见路线图 §1.1 / 阶段三；**DeepSeek 真摘要与标签（C）已落地**（见 §8.2）。

# 7. 异步任务与状态流转

## 7.1 资料解析任务

```text
uploading（文件）/ validating（链接）
├── requires_connection（未连接且平台需要登录）
├── parsing → structuring → indexing → ready
└── parse_failed
    ├── parsing（用户手动重试）
    └── link_only / attachment_only（连续失败三次后自动降级）
```

- 后台解析即使用户离开页面仍继续；
- 创建任务时同步创建资料卡片并置于列表底部，解析进度以百分比持续更新；
- 解析失败保留失败卡片；连续三次失败后自动降级，用户仍可无限次手动重试；
- `ready` 前资料不参与搜索、RAG 和来源引用。

## 7.2 索引更新任务

触发条件：资料首次保存、资料重新解析成功、标题/摘要/主体文本编辑、资料移动、标签变化、资料删除。

- 首次保存：正文清洗 → 切片 → embedding → 写入 pgvector → `ready`；
- 文本编辑：保留旧索引可用，生成新索引成功后替换；
- 标签/知识库移动：立即更新过滤元数据；
- 删除：优先从检索索引移除，再完成关联数据删除；
- 任何索引失败均记录可观测错误；资料保存不回滚，但状态显示为“索引更新失败”，并自动重试。该状态的资料不得被不完整索引引用。

## 7.3 平台会话状态

```text
disconnected → connecting → connected → expired → reconnecting → connected
                         └──────────────→ disconnected
```

- `connecting` 与 `reconnecting` 是受控浏览器中用户完成登录的临时状态；
- 会话过期可由解析时鉴权失败或定期验证发现；
- `expired` 平台的资料导入必须先重新连接或选择仅保存链接；
- 断开连接只清除平台会话，不影响既有资料及索引。

## 7.4 笔记自动保存、生成与同步

- 编辑器变更以 1–2 秒防抖自动保存；切换笔记、离开编辑页、生成前后均需立即落库；保存失败保留本地编辑状态并提供重试；
- “生成笔记”顺序为：持久化当前内容 → 创建 `before_generate` 修订 → 读取当前素材与想法 → 生成富文本与引用映射 → 原子替换笔记正文 → 同步所有关联知识库资料；
- 每个同步资料更新均触发独立索引更新任务；任一同步失败时保留笔记正文和其余成功同步，记录失败目标并自动重试；
- 任一同步资料编辑时采用笔记为协调中心：先更新笔记，再向其余关联资料扇出；服务端使用版本号/事务避免循环触发与静默覆盖；
- 当前编辑会话的撤销/重做由编辑器维护；`note_revisions` 用于页面关闭后的历史恢复，不替代普通撤销栈。

# 8. AI 与内容处理规格

## 8.1 标准化解析结果

所有解析器必须返回以下字段，缺失内容使用 `null` 或空数组，禁止伪造：

```json
{
  "platform_code": "xhs",
  "source_url": "https://...",
  "canonical_url": "https://...",
  "title": "...",
  "author_name": "...",
  "published_at": "2026-08-13T00:00:00Z",
  "content_text": "...",
  "content_excerpt": "...",
  "source_tags": ["..."],
  "media_descriptions": ["..."],
  "parse_warnings": []
}
```

## 8.2 AI 结构化

> **已落地（2026-09-15）：** `parse-material` 在正文可用且即将标 `ready` 时同步调用 DeepSeek enrichment（摘要 + 约 3 标签）；失败不阻断入库，摘要回退正文截断；`materials.tags_user_edited` 为真时重新解析不覆盖标签关系，摘要每次重写。本切片不做历史资料批量回填。

- 生成模型：DeepSeek Chat；
- 输入：已解析的标题、内容主体、来源平台与可用元数据；
- 输出：简明摘要和资料标签；
- 用户对摘要和标签的编辑优先于 AI 结果；手改标签置 `tags_user_edited=true`；
- AI 生成摘要或标签失败不删除已入库资料；资料可保持 `ready`（截断摘要 / 标签可空），用户可「重新解析」；
- 未得到主体文本时不可生成向量索引。

## 8.3 向量检索

- 向量模型：阿里云百炼 `text-embedding-v4`；
- 重排序：阿里云百炼 `qwen3-rerank`（失败回退本地 light rerank）；
- 向量库：Supabase Postgres + pgvector；
- 召回：向量 RPC `match_material_chunks` + 关键词 RPC `match_material_chunks_keyword`，RRF 融合后再 diversify / rerank；
- 召回对象：当前用户、`ready` 状态的资料片段；
- 标签过滤先于召回；多标签为 AND；
- 搜索与对话均排除 `link_only`、删除中、已删除、索引更新失败资料；
- 返回结果必须携带资料 ID、知识库 ID、标题、平台、原文位置和内容片段，以支持来源展示；
- 详细参数见 `docs/superpowers/specs/2026-09-16-ai-accuracy-multi-recall-rerank-design.md`。

## 8.4 RAG 生成提示约束

系统提示应约束模型：

1. 仅根据提供的资料片段和会话上下文回答；
2. 没有依据时直接回复「暂无相关资料」；
3. 关键结论句末标注 `[n]`；不要写文档名、不要末尾汇总参考列表；
4. 资料冲突时分别标注不同来源观点；
5. 不输出“已阅读资料但实际未引用”的泛化结论。

## 8.5 首页通用 AI 与笔记生成约束

- 首页通用 AI 默认使用 DeepSeek；无知识库/标签范围时可按用户联网开关使用模型通用能力，且必须将 `answer_mode=general` 写入回答与灵感卡片；不得输出“参考知识库”计数、资料标题或伪造引用；
- 只要存在知识库或标签范围，服务端必须强制 `answer_mode=rag` 与 `online_enabled=false`，不得相信客户端状态；
- 严格 RAG 回答和其灵感卡片必须保存可追溯的资料引用快照；
- 笔记生成只读取当前 `note_inspiration_cards`、其排序及 `user_thought`，不得私自扩展到其他卡片、用户资料或外部网络；
- 对 RAG 卡片，生成的关键结论必须输出到富文本引用节点，并映射至灵感卡片与资料引用快照；对通用 AI 卡片，禁止生成资料型引用；
- 生成结果是可编辑正文而非不可修改结论；每次生成前必须建立修订记录。

# 9. 验收标准

## 9.1 账户与数据隔离

- 注册须填写用户名；注册后自动创建默认知识库；侧栏展示 `display_name`；
- 默认知识库可重命名、不可删除；
- 两个不同账户不能检索、读取、修改或引用彼此资料；
- 注销后无法登录，且相关数据与平台会话均不可恢复。

## 9.2 知识库与资料

- 创建或重命名为同名知识库时被拒绝；
- 自定义知识库删除后，其中资料及向量不再被搜索或对话检索；
- 资料必须保存到当前选中知识库；导入期间不可换库；
- 资料移动后只在目标知识库出现；
- 删除资料后，后续 AI 不引用它，历史引用显示“该资料已删除”；
- 新增资料卡片在进入详情后新增标记消失。

## 9.3 平台连接与导入

- 用户可分别连接小红书、抖音、知乎、B 站、微信公众号，每个平台最多一个账号；
- 其他网页匿名解析，不要求用户注册目标站；
- 主流平台未连接时仍可保存链接并尝试解析或选择「仅保存链接」；连接为可选增强；
- 连接成功后，原链接自动继续解析；
- 会话失效时可重新连接后继续解析；
- 解析失败资料保留重试/删除，连续三次失败自动降级为仅链接或仅附件；
- 降级资料不进入搜索和 AI 问答；
- 评论区与视频语音转写不进入资料正文、摘要、标签、切片或向量；已有字幕/文案写入正文并生成 AI 摘要；抖音/B 站预览支持应用内嵌播放且不落盘视频文件；
- 图片 OCR 属于 V1 入库能力。

## 9.4 搜索、对话与脑图

- 知识库搜索按名称关键词匹配；资料搜索仅匹配当前知识库 `ready` 资料的标题、摘要和标签，不调用向量检索；
- 来源平台筛选可与资料关键词搜索和排序同时生效；
- 多个 #标签只检索同时具备全部标签的资料；
- 回答的关键结论均可打开来源引用；
- 资料不足时 AI 不生成无来源完整结论；
- 用户可新建、查看、继续和删除会话；
- 脑图只能由用户主动触发，且仅基于对应回答与已引用资料；成功后打开历史会话仍可查看。

## 9.5 笔记与灵感卡片

- 首页默认问题生成 `general` 回答；选择知识库或标签后生成严格 RAG 回答；知识库模块中不允许产生通用 AI 回答；
- 用户收藏片段时，卡片仅保存选中文字而非整条回答，同时保存原问题、回答模式和来源快照；原会话或资料删除后，卡片正文仍可读且来源被标记为不可用；
- “我的笔记”列表栏按“笔记本筛选与搜索同一行 → 最近编辑分组列表”顺序展示；笔记本筛选默认“全部笔记”；页头无「个人记录」，「新建笔记」为黑色主按钮；
- 「新建笔记」进入全屏且不显示素材面板或生成按钮；「整理为笔记」进入全屏且显示素材面板；双栏全屏 icon 在已有素材时显示素材面板；返回到「我的笔记」并选中该笔记；
- 灵感卡片页去掉筛选；搜索延伸至「整理为笔记」前；默认不展示复选框；点击“整理为笔记”后才进入选择模式（内嵌圆角选择条 + 左浅右深弱渐变），至少选择一张才可开始整理；卡片详情通过弹窗展示；
- 从卡片整理创建的笔记包含可收起素材面板；拖拽排序、修改“我的想法”、增删素材与正文编辑均自动保存；
- 点击“生成笔记”后在同一编辑页替换正文，且生成前存在可恢复的后台修订；撤销/重做能覆盖本会话中的文字、格式、生成与素材变更；
- RAG 卡片生成的正文引用为内联 `[n]`（绑定卡片）；hover 预览、点击打开对应灵感卡片详情，预览不得超出视口；通用 AI 卡片不显示伪造资料引用；
- 同一灵感卡片可被多篇笔记复用；删除笔记或移除其素材不删除灵感卡片；
- 一篇笔记最多属于一个笔记本、可同步到多个知识库；编辑笔记或任一同步资料后，所有关联位置的正文一致；
- 删除同步资料或其知识库只解除该库关联，原笔记和其他关联资料保留；删除笔记时，所有同步资料与索引被删除；
- 删除笔记本确认弹窗可分别完成“仅删除笔记本，笔记未归类”与“连同笔记及其同步资料永久删除”。

## 12.2 抖音 / B 站视频（已确认 · 方案 A）

**目标：** 收藏后既可在应用内看视频，也可对文本做 AI 摘要与 RAG。

| 层 | 规则 |
| --- | --- |
| 播放 | 新开预览窗内嵌播放器；**点击再播放**；不落盘视频文件；优先 embed，其次临时可播 URL；失败则「在原站打开」 |
| 正文 `content_text` | 文案/简介 + **已有字幕文本**（无字幕则仅文案/简介） |
| AI 摘要 `summary` | 基于正文生成，与普通网页/文档同一套摘要管线 |
| 标签 / 切片 | 与其他 `ready` 资料相同；正文参与检索切片 |
| 不做 | 语音转写（ASR）、评论区、永久视频托管 |

有文案/字幕即可 `ready`（即使播放信息缺失）；仅链接可打开且无任何文本时按失败/降级规则处理。

### 14.1 RAG A′ 管线

| 步骤 | 实现 |
| --- | --- |
